# SQL-Moderno

Lo que Veremos:

• Conceptos básicos de SQL: bases de datos, tablas, filas y columnas.

• Tipos de comandos SQL: DDL, DML, DCL y TCL.

• Consultas de datos: SELECT, WHERE, ORDER BY, LIMIT y FETCH.

• Agregaciones: COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING.

• UNIONES: INNER, LEFT, RIGHT, FULL, CROSS.

• Subconsultas, CTE y funciones de ventana.

• SQL avanzado: vistas y procedimientos.
